# Auto-build of [Node.js](https://github.com/nodejs/node) with shared OpenSSL
Built and packed against last + previous major for Debian & AlmaLinux, Arch rolling.
## Installation
Take the latest package from [release](https://github.com/GauriSpears/node-package/releases) and:
### Debian:
apt-get install nodejs-shared[yourversion].deb
### Arch:
pacman -U nodejs-shared[yourversion].pkg.tar.zst
### Alma:
dnf install nodejs-shared[yourversion].rpm
